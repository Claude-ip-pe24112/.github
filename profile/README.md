<p>第一块，供给稀缺。原生段的来源是运营商直接分配给最终用户的地址，数量受制于实际装维覆盖，不可能像机房那样按需批量开。供给有限而需求增长，价格自然往上走。</p>

<p>第二块，核验成本。要证明一段地址是原生的，需要查注册信息、看段划分、确认分配链条。这些工作要做在每一条线路上，人力成本会摊进单价。</p>

<p>第三块，维护成本。原生段的表现在使用中会衰减，服务方要持续监控、及时替换，这部分运维投入同样要摊进价格。</p>

<p>三块之外，还有一个变量：地区的稀缺程度。热门地区供给相对多，价格温和；冷门地区供给少，价格高且不易扩容。做多地区业务时，要按地区分别核算。</p>

<p>所以看到原生报价，先问三件事：段能不能查、分配链条能不能说清、更换政策是什么。三问答完，两个报价才有可比性。答不上来的，贵也只是贵在标签上。</p>

<p>关于计费，原生方案通常按月或按年，按量计费的少。短期使用成本不划算，长期使用才谈得上性价比。</p>
